## Article Format Rules

Each article needs:

- one specific example
- one table or structured block
- one FAQ section
- one internal link to a tool
- one internal link to a trust/methodology page
- one CTA aligned with the reader's emotional state

Avoid repeated templates like:

- "How to make it work"
- four generic bullets every time
- deterministic soulmate language
- vague advice like "communicate better"
