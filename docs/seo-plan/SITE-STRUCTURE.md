## Highest Priority New Pages

### `/reports/private-compatibility-read`

Purpose: sell the paid report before checkout.

Must include:

- "For the connection you keep thinking about"
- Report sections preview
- Example snippets
- What the report will not claim
- Privacy note
- Price
- FAQ
- CTA to run calculator first

### `/reports/sample`

Purpose: prove the paid report is not generic.

Must include:

- Fictional pair
- Visible sections
- Real specificity
- Blurred/locked deeper sections
- CTA to unlock your own

### `/tools/birth-date-compatibility`

Purpose: target the cleanest high-intent search.

Must include:

- Calculator embedded above fold
- Short explanation
- Internal links to life path, crush birthday, moon sign, and methodology pages
- FAQ schema

### `/tools/moon-sign-compatibility`

Purpose: win more precise compatibility intent.

Must include:

- Explain why birth time matters
- Pair comparison UI
- CTA to calculator exact mode
- Link to Cancer Moon and moon-sign articles

## Internal Linking Rules

Every article should link to:

- one tool page
- one methodology/trust page
- two related articles
- one paid report page when context fits

Every tool page should link to:

- `/how-it-works`
- `/reports/private-compatibility-read`
- 3 supporting articles
- 1 adjacent tool

Every paid report page should link to:

- `/privacy`
- `/disclaimers`
- `/about`
- `/how-it-works`

## Sitemap Quality Gate

Only include pages that have:

- unique title
- unique meta description
- crawlable static HTML
- canonical URL
- at least 500 words for article/guide pages
- internal links in and out
- no raw result pages

Do not index:

- `/result`
- checkout/session pages
- API routes
- temporary previews
- duplicate slash/query URLs
