# hrefStack Free Plan Testing Framework

## Quick Setup (5 minutes)
1. Go to https://app.hrefstack.com/auth
2. Sign up with your email (use a burner or matchbybirth.com email)
3. Select **Free Plan** (no credit card)
4. Connect a test WordPress site or use their demo environment

## Quality Evaluation Checklist

### Pass Criteria (✓)
- [ ] Reads like human-written astrology content
- [ ] Accurate planetary placements and aspects
- [ ] No generic "AI slop" phrases ("in today's fast-paced world...")
- [ ] Includes specific, actionable insights
- [ ] Matches your brand's "premium, intentional, clean-simple" style
- [ ] Would make your daughter proud (quality check)

### Fail Criteria (✗)
- [ ] Obvious AI patterns (repetitive phrasing, generic advice)
- [ ] Inaccurate astrological claims
- [ ] Overpromising or fake-scientific language
- [ ] Cramped, over-designed layout
- [ ] Feels like content mill material
