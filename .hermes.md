# MatchByBirth Project Rules

## Project
Astrology compatibility SaaS — matchbybirth.com. Live, monetized ($9.99/mo).

## Stack
- Next.js (apps/web)
- Supabase (DB, auth, storage)
- Vercel (hosting)
- Stripe (subscriptions)
- Printful (merch)
- Sanity (blog CMS)

## Working Directory
`/Users/alijahfox/MatchByBirth`

## Key Files
- Blog posts (manual): `apps/web/src/data/posts/index.js`
- Blog posts (auto-generated): `sanity-posts.generated.js` — NEVER hand-edit
- Shop page: `apps/web/src/pages/ShopPage.jsx`
- Printful integration: `api/_lib/printful-products.js`

## Rules
- Blog posts go in `index.js` (manual array), NOT in sanity generated file
- Always verify build after changes (`npm run build`)
- Commit and push after each blog post
- SEO: every post needs meta description, OG tags, structured data
- Revenue-first: every change should either convert visitors or retain subscribers
